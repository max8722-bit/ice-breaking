# ICE BREAKING

휴대폰의 기울기 센서로 얼음 조각을 안내해 무너진 얼음집을 완성하는 세로형 웹 게임 프로토타입입니다.

## 공개 게임 링크

https://max8722-bit.github.io/ice-breaking/

## 실행

별도 설치 없이 `index.html`을 열어도 실행됩니다. 기울기 센서는 보안 연결(HTTPS)에서 가장 안정적으로 동작하므로, 휴대폰 테스트 시 로컬 서버 또는 배포 URL을 사용하세요.

```bash
python3 -m http.server 4173
```

그 후 브라우저에서 `http://localhost:4173`을 엽니다.

## 조작

- 휴대폰: 시작 버튼으로 센서 권한을 허용한 뒤 좌우로 기울입니다.
- 데스크톱: `←` / `→` 또는 `A` / `D` 키를 사용합니다.
- 터치·마우스: 게임 화면을 누른 채 좌우로 드래그합니다.
- `Space`: 일시정지/계속

## 게임 규칙

- 깨진 이글루에 얼음 조각 3개를 안착시키면 다음 구간이 섬 아래쪽으로 이어집니다.
- 다음 작업대에서 캐릭터가 다시 등장하고 새로운 깨진 이글루를 계속 수리합니다.
- 전체 게임은 10개 스테이지이며, 1단계는 모닥불만 등장하고 2단계부터 펭귄, 3단계부터 틈새 구멍이 추가됩니다.
- 이후 스테이지마다 방해물 수, 펭귄 속도, 모닥불 피해량과 체력 소모량이 점차 증가합니다.
- 방해 오브젝트는 새 게임과 각 스테이지 시작 시 얼음 타일 위에 무작위로 다시 배치됩니다.
- 얼음섬 타일은 기존 선 색상으로 한 칸씩 번갈아 면을 채운 체크무늬이며, 반대 칸에는 별도 색상을 칠하지 않습니다.
- 10단계의 이글루까지 완성하면 최종 클리어입니다.
- 캐릭터 체력은 진행 중 감소하고, 조각을 잃으면 추가로 줄어듭니다. 체력이 0%가 되면 게임 오버입니다.
- 이글루를 완성하면 캐릭터 체력이 일부 회복됩니다.
- 펭귄은 조각을 밀고, 모닥불은 내구도를 녹이며, 타일 틈새 구멍은 조각을 빠뜨립니다.
- 얼음 조각이 모닥불의 가열 범위에 한 번이라도 들어가면 해당 조각은 계속 녹은 이미지를 유지하며, 두 얼음 이미지는 중앙 하단 기준으로 정렬됩니다.
- 펭귄의 양팔과 양발은 몸통과 분리된 파츠로 움직이며, 이동 방향이 바뀌면 몸 전체가 좌우 반전되어 얼굴이 진행 방향을 바라봅니다.
- 펭귄의 왼팔은 오른팔 리소스를 좌우 반전해 사용하며, 양팔은 이전 배치보다 5px 위에 놓입니다. 큰 오른발은 왼쪽에, 작은 왼발은 오른쪽에 배치되고 작은 발 레이어가 위에 놓입니다.
- 새 게임마다 좌우 절벽의 파인 위치와 깊이가 달라져 이동 경로가 바뀝니다.
- 작은 이글루는 섬 최하단의 왼쪽·가운데·오른쪽 중 한 곳에 무작위로 배치됩니다.
- 이글루의 외형과 안착 영역은 바닥 타일 기준 2×2칸입니다.
- 조각을 잃으면 작업대에서 새 조각을 만들어 다시 도전합니다.
- 얼음 조각은 회전하지 않은 채 이동하며, 지나간 타일에는 조각 너비만큼 넓은 물길 자국이 남습니다. 흔적은 1.35~1.65초 안에 빠르게 사라져 길이가 짧게 유지됩니다.
- 상단 작업대의 캐릭터는 4프레임 망치질 모션으로 얼음 조각을 만든 뒤 조각을 출발시킵니다.
