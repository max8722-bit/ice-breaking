# ICE BREAKING

휴대폰의 기울기 센서로 얼음 조각을 안내해 무너진 얼음집을 완성하는 세로형 웹 게임 프로토타입입니다.

## 공개 게임 링크

https://max8722-bit.github.io/ice-breaking/

## 실행

별도 설치 없이 `index.html`을 열어도 실행됩니다. 기울기 센서는 보안 연결(HTTPS)에서 가장 안정적으로 동작하므로, 휴대폰 테스트 시 로컬 서버 또는 배포 URL을 사용하세요.

```bash
python3 -m http.server 4173
```

그 후 브라우저에서 `http://localhost:4173`을 엽니다.

## 조작

- 휴대폰: 시작 버튼으로 센서 권한을 허용한 뒤 좌우로 기울입니다.
- 데스크톱: `←` / `→` 또는 `A` / `D` 키를 사용합니다.
- 터치·마우스: 게임 화면을 누른 채 좌우로 드래그합니다.
- `Space`: 일시정지/계속

## 게임 규칙

- 얼음집에 얼음 조각 3개를 안착시키면 완성입니다.
- 펭귄은 조각을 밀고, 모닥불은 내구도를 녹이며, 타일 틈새 구멍은 조각을 빠뜨립니다.
- 새 게임마다 좌우 절벽의 파인 위치와 깊이가 달라져 이동 경로가 바뀝니다.
- 작은 이글루는 섬 최하단의 왼쪽·가운데·오른쪽 중 한 곳에 무작위로 배치됩니다.
- 조각을 잃으면 작업대에서 새 조각을 만들어 다시 도전합니다.
